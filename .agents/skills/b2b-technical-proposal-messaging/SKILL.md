# B2B Technical Proposal Messaging

## Existing Asset Gate

For an existing asset, read the relevant source before final titles, narrative restructuring, or rewritten body copy. Record the source/version readout and inspect copy, process data, navigation, interactions, demos, evidence, and responsibility boundaries. Interactive behavior is semantic content.

If material is missing or a version conflict changes meaning, state the gap or conflicting versions. Do not reconstruct unseen content from memory.

## Content Model

Before strategy, model each affected section:

- current purpose and source facts;
- subsections or meaningful steps;
- interaction/evidence;
- claims and proof status;
- Human / Program / AI responsibilities;
- repetition, contradiction, version drift, protected content, and open gaps.

Preserve meaningful process steps before summarizing them.

## Positioning Snapshot

After the Content Model, establish buyer, end user, technical reviewer, status quo, customer problem, consequence, primary value, differentiated mechanism, proof status, and commercial next action. `proven`, `proposed`, `concept simulation`, and `unknown` are distinct. Unknown is valid; never invent evidence.

## Narrative Map

Define the beliefs the reader must acquire in sequence. For each section state the reader question, core message, supporting evidence/interaction, exit understanding, and dependency on the next section. Do not force a fixed landing-page framework.

## Section Content Contract

Before rewriting a section, define: Section Purpose, Reader Question, Source Facts, Interaction / Evidence, Core Message, Body Structure, Proof / Claim Boundary, and Takeaway.

Prefer concrete customer situations and actions over adjectives. Attribute deterministic calculation, rule evaluation, geometry, safety logic, and exact quantities to the actual responsible system. AI may be prominent only where its real role is explicit.

## Titles Are Downstream

Titles come after the Section Content Contract. Generate multiple frames and score clarity, relevance, value, differentiation, credibility, title-body fit, and conversion fit. A promotional title that misrepresents the body loses.

## Cross-Section Review

Check narrative progression, duplication, premature conclusions, terminology, unsupported claims, responsibility drift, concept/demo wording, title-body fit, and missing commercial action. Keep `current-state diagnosis` or `source fact` separate from every `strategic recommendation` or `proposed change`.

## Greenfield Route

When no existing asset exists, skip the Existing Asset Gate and start with the Positioning Snapshot. Mark unknown inputs instead of blocking or inventing them.

## Handoff

Return source/version readout, Content Model, Positioning Snapshot, Narrative Map, Section Content Contracts, title matrices, recommendation, cross-section review, evidence gaps, and handoff items. Route engineering-facing copy through `eden-engineering-copy` in `strict-review` mode before external publication.
