# ACT01 Commercial Message Design

## Goal

把 ACT01 從「客戶需求／我們目標／真正難點／先理解現況」的開發敘事，改成非技術客戶能在數秒內理解的成交前台：先知道這套 AutoCAD 外掛能替他整理什麼、最後能看到什麼，再往下閱讀 ACT02–ACT04 的證據與操作。

## Scope

只修改 ACT01 與它直接使用的內容資料／測試。ACT02–ACT06、ACT04 十二步 CAD 互動、框選契約、計算資料與動畫語意全部保持不變。

## Reading Order

1. 小標：`ACT 01 / AutoCAD × AI 智能作業提案`
2. H1：`AutoCAD 施工圖長度與數量自動驗算`
3. 核心價值句：`繪圖完成後，原本需要逐段查看、記錄、加總與清點的工作，由外掛集中整理。`
4. 四個客戶結果：
   - 每段長度：施工線逐段整理，可查看個別長度。
   - 施工總長：同一施工範圍的外部、深井與總長集中顯示。
   - 元件數量：依目前施工範圍整理指定施工元件數量。
   - AI 查詢：針對目前施工範圍詢問結果、組成與需要確認的內容。
5. 範圍可信度提示：`只整理這次要算的範圍`；用 `6 樓外部施工範圍` 說明其他樓層、深井或不符合條件物件不混入。
6. 收尾：結果直接在 AutoCAD 內查看與確認，需要進一步了解時，再由 AI 協助查詢目前施工範圍的結果與依據。
7. 六章快速導覽移到上述內容之後，保留 anchor navigation；不新增 D3、框選、AI 問答或其他重互動。

## Commercial Rules

- ACT01 只回答「這套工具實際可以幫我做什麼？」；不提前教客戶 ACT04 的操作步驟。
- 不出現 C#、Rule Engine、CAD API 等底層模組分工。
- 不宣稱已量測的速度提升、工時節省、錯誤率下降或穩定性提升。
- 繪圖人員的工程判斷與 ACT04 的實際操作責任不改寫。
- `main` 既有 ACT04 十二步是操作證據，不在 ACT01 重複演示。

## Interaction

ACT01 保留輕量導航互動：六章 anchor link、hover、focus。核心價值與四個結果必須不用點擊即可讀懂。六章導覽放在主要價值內容之後，避免客戶先看到目錄才知道網站在提案什麼。

## Data Contract

`heroContent` 改為：`eyebrow`、`title`、`lead`、`outcomes`、`scopeNote`、`closing`。移除舊 `sections` 四段資料，避免未顯示的舊敘事仍留在主要內容來源與 Copy Gate 掃描範圍。

## Acceptance

- ACT01 H1 為 `AutoCAD 施工圖長度與數量自動驗算`。
- 四個結果固定為 `每段長度 / 施工總長 / 元件數量 / AI 查詢`。
- `6 樓外部施工範圍` 保留為具體範圍例子。
- 快速導覽仍可跳轉六個 ACT，但位於主要價值內容之後。
- ACT04 的 `futureFlowSteps` 長度仍為 12，內容與互動不因本次 ACT01 變更而修改。
- Copy Gate、Svelte check、Vitest、static build 全部通過。
